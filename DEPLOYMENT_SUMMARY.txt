QUICKEST PATH: GitHub Pages (5 minutes)
================================================================================

1. Go to https://github.com and sign in

2. Create new repository:
   - Name: bank-reconciliation
   - Public
   - Click "Create repository"

3. Upload your file:
   - Click "Add file" → "Upload files"
   - Drag and drop: reconciliation_website.html
   - Click "Commit changes"

4. Enable GitHub Pages:
   - Click "Settings"
   - Click "Pages" (left sidebar)
   - Source: "Deploy from a branch"
   - Branch: "main / (root)"
   - Click "Save"
   - Wait 1 minute

5. Your website is LIVE at:
   https://YOUR_USERNAME.github.io/bank-reconciliation/reconciliation_website.html

================================================================================
TROUBLESHOOTING COMMON ISSUES
================================================================================

Problem: Can't open reconciliation_website.html by double-clicking
Solution: Use the Python server instead:
  python ba/serve.py
  Then go to: http://localhost:8000/reconciliation_website.html

Problem: File upload doesn't work locally
Solution: Use served via Python (file:// protocol has restrictions)

Problem: GitHub Pages shows 404
Solution:
  - Check file is named exactly: reconciliation_website.html
  - Check file is in root of repo (not in subfolder)
  - Wait 1-2 minutes for deployment
  - Check Settings → Pages is enabled

Problem: Need HTTPS
Solution: All deployment platforms provide FREE HTTPS automatically

Problem: Want to change the website
Solution: Edit reconciliation_website.html and re-upload (auto-deploys)
