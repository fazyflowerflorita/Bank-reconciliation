# GitHub Pages - Quick Start (5 Minutes)

## ⚡ Fastest Way to Deploy

### Step 1: Create GitHub Repository (2 min)

1. Go to **https://github.com** and sign in (create account if needed)
2. Click **+** (top right) → **New repository**
3. Fill in:
   ```
   Repository name: bank-reconciliation
   Description: Intelligent Bank Reconciliation Website
   Public: ✓ (checked)
   ```
4. **Skip** all other options
5. Click **Create repository**

### Step 2: Upload Your File (2 min)

1. Click **Add file** → **Upload files**
2. Drag and drop this file:
   ```
   reconciliation_website.html
   ```
3. Scroll down and click **Commit changes**

### Step 3: Enable GitHub Pages (1 min)

1. Click **Settings** (top right of repo)
2. Click **Pages** (left sidebar)
3. Under "Build and deployment":
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)`
4. Click **Save**
5. **Wait 30 seconds** ⏳

### Step 4: Access Your Website ✅

Your live website is now at:
```
https://YOUR_USERNAME.github.io/bank-reconciliation/reconciliation_website.html
```

Example:
```
https://john-doe.github.io/bank-reconciliation/reconciliation_website.html
```

## 🆘 Troubleshooting

### "404 - Page not found"
- Check spelling of your URL
- Make sure file is named `reconciliation_website.html` (exact case)
- Wait 1-2 minutes for deployment to complete
- Check GitHub Pages is enabled in Settings

### "File not found"
- Go to your repo
- Check that `reconciliation_website.html` is there
- Check repo is **Public** (not Private)

### "File upload doesn't work"
- Use HTTPS (should be automatic)
- Clear browser cache
- Try a different browser
- Try in incognito mode

### GitHub Pages not appearing
- Go to Settings → Pages
- Verify Source is set to "Deploy from a branch"
- Verify Branch is "main" or "master"
- Click **Save** again
